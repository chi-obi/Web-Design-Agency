# Web-Design-Agency
Visually appealing website for a Web Design Agency 

The project required manipulating CSS properties effectively, such as block and inline-block to ensure that elements stack vertically on smaller screens rather than displaying side by side, and provide a clean website aesthetics as well as functionality. The focus was on creating a visually appealing website for a Web Design Agency that exemplifies simplicity and clean design. 
The goal is to showcase the agency's services effectively and ensure the site's responsiveness across different devices, particularly smaller screens like iPhones.

Important concepts and tools:
1. CSS Display Property - Understanding how different display types can affect the layout.
2. Floats - Utilizing float properties to align elements correctly.
3. Responsiveness - Implementing responsive design using media queries to achieve an adaptive layout across various screen sizes.
   
Learning outcomes: 
1. Gained practical experience in CSS.
2. Enhanced my understanding of responsive web design.
3. Applied these skills creatively to build a beautiful, functional website.
